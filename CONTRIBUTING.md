# Contributing

Bug reports and questions are welcome as GitHub issues.

bekiper is dual-licensed (see [COMMERCIAL.md](COMMERCIAL.md)). To keep that
possible, pull requests can only be merged after the contributor has signed a
contributor license agreement that grants the copyright holder the right to
relicense the contribution. Open an issue before starting larger work, and we'll
send you the agreement.

This repository is exported from the main development repository. Accepted
changes are applied there and appear here with the next release.
